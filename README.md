# Misti-go

Android app starter written in Kotlin. The Android project lives in `frontend/`.

## Build a debug APK

Install Android SDK Platform 36 and set `ANDROID_HOME` (or open the project in Android Studio), then run:

```powershell
cd frontend
./gradlew assembleDebug
```

The APK is written to `frontend/app/build/outputs/apk/debug/app-debug.apk`.
